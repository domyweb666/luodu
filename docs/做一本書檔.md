# 把做好的書放進蘿讀

書在電腦上做（字和圖），打包成一個 `.luodubook` 書檔，傳到手機，點開就進書架。

## 1. 準備一個資料夾

資料夾名稱隨意。裡面放：

```
小芽的鞋子/
├── 書.txt
├── 1.jpg
├── 2.jpg
├── ...
└── 封面.jpg    （可以沒有，沒有就用第 1 頁當封面）
```

圖的檔名就是頁碼，jpg 或 png 都可以。

圖上不要有字，字由 app 排在圖下面。這樣之後要改字、升級成三歲版，圖都不用重做（書稿 2-13 第 5 條）。

**圖的方向**：app 目前只有直式畫面，圖做成直的（3:4 或 4:5）或正方形在手機上最大。橫的圖放得進去，但會變小。

## 2. 寫 書.txt

```
書名：小芽的鞋子
代號：xiaoya-shoes

# 第 1 頁
小芽的鞋子，不見了。
提示：停三秒，等她說「鞋鞋」。

# 第 2 頁
在床下面嗎？
沒有。

# 第 3 頁
在這裡！
```

規則只有四條：

- 開頭兩行是書名和代號。代號只能用英文字母、數字、連字號，一本書一個，定了就不要改。
- 每一頁用 `#` 開頭的一行分開，`#` 後面寫什麼都可以。
- `#` 下面的字就是那一頁要念的。寫兩行，畫面上就是兩行。
- `提示：` 開頭的那一行是給大人看的小字，可以不寫。提示裡的「她」不會自動換成名字，要寫誰就直接寫。

## 3. 打包

第一次用要先裝一個套件：

```bash
pip install pillow
```

然後在 `luodu` 資料夾裡執行，後面接你那本書的資料夾路徑：

```bash
python tools/pack_book.py "D:\我的書\小芽的鞋子"
```

成功的話，書檔會出現在那個資料夾的旁邊，檔名是 `代號.luodubook`，畫面上會列出每一頁的第一句字讓你對一下。圖太大會自動縮到長邊 1600。

哪裡不對它會直接說，例如「第 3 頁找不到圖」。

## 4. 傳到手機

兩種方法擇一：

- 把書檔用 LINE、Email 或 iCloud 雲碟傳到 iPhone，在 iPhone 上點那個檔案，選「蘿讀」打開。
- 先把書檔存進 iPhone 的「檔案」，然後在蘿讀裡點書名 → 書架最下面的「加一本做好的書檔」。

app 會先問「把《小芽的鞋子》加進書架？」，按「加進書架」就好了。

## 改了書想更新

改完圖或字，重新打包、重新傳一次。只要代號沒變，app 會問「換掉《小芽的鞋子》的內容？」，按下去書頁換新的，念過的紀錄和葉子都留著。

## 注意

- 小芽的書檔不要放進 `luodu` 這個資料夾裡再推上 GitHub。這個 repo 是公開的。`.luodubook` 檔已經設定成不會被 git 收進去，只有 `samples/red-ball` 那本範例例外。
- 備份檔（匯出備份）只有念的紀錄，不包含書頁。換手機的時候，紀錄用備份還原，書檔要重新傳一次。
