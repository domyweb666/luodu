# 標準清單

## 片 1：骨架

### 必須做到（你在手機上測得出來的）

1. 第一次打開，看到「今晚念的是哪一本？」、一個書名輸入框、一顆「種下去」。
2. 沒打字時「種下去」是灰的，按不動。打了字才亮。
3. 按「種下去」後，畫面換成書名、一行次數、一顆「念完了」。次數那行寫「還沒念過」。
4. 按一次「念完了」，次數變「第 1 次 · 還在土裡」。按到第 3 次變「念了 3 次」。
5. 把 app 從背景滑掉、重新打開，書名和次數都還在。

### 絕不准做

- 不准出現蘿蔔圖、提示卡、訊號、書架、蘿蔔田、設定。那些是後面的片。
- 不准連網。
- 不准把任何金鑰、帳號寫進程式或 repo。

### 意圖

這片要證明的只有兩件事：雲端的 Mac 編得出這支 app；資料存得住。畫面長得醜沒關係，片 3 之後才會像原型。

### 機器驗的部分

- 雲端編譯通過。
- 自動測試通過：加書、念三次、把資料重新從檔案讀回來，書和次數都對。
