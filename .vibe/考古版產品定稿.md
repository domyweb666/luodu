# 考古版產品定稿：蘿讀（網頁手感原型）

> 考古版。這是我讀 `index.html` 讀出來的行為，沒有在 iPhone 上實際操作過。你用的時候發現跟下面寫的不一樣，就是我讀錯了，跟我說。
> 「你的反應」欄等你填：預期／意外／落差。

## 整體

一個 app，三頁，左右滑動切換，上方三個小圓點標示現在在哪頁。打開永遠先到中間的主畫面。左邊是蘿蔔田，右邊是設定。

資料全部存在瀏覽器裡，只有四樣：書、每一次念的紀錄、現在選的是哪本、她的名字。沒有帳號，沒有連網。

## 主畫面

| # | 實際行為 | 你的反應 |
|---|---|---|
| 1 | 一本書都沒有時，畫面只有一句「今晚念的是哪一本？」、一個書名輸入框、一顆「種下去」。打了字按鈕才亮，按 Enter 也可以。 | |
| 2 | 有書之後，最上面是一顆膠囊：封面（沒封面就顯示書名第一個字）加書名。按它會從底部滑出書架。 | |
| 3 | 中間是蘿蔔。念 0 到 2 次只看得到土和一顆種子，土上有三個小點，念幾次亮幾個。 | |
| 4 | 第 3 次冒芽：蘿蔔身體露出來，有臉，頭上兩片小葉子。 | |
| 5 | 第 4 次開始，每念一次多一片葉子。畫面上最多畫 36 片，第 40 次以後葉子數不再增加。 | |
| 6 | 蘿蔔身體會越念越長，長到第 70 次停。葉子也會慢慢變大，到第 60 次停。 | |
| 7 | 蘿蔔下面一行小字：「還沒念過」／「第 N 次 · 還在土裡」／「念了 N 次」。 | |
| 8 | 字下面一張卡片，給今晚的一個提示。前兩次是「前三次只念不問」，第 2 次念完是「再一次就冒芽」。 | |
| 9 | 第 3 次以後，提示從五個字裡給一個：等、接、加、誇、再。給哪個字，看「她接話了」這個訊號累積幾次，每 3 次往下一個字走。 | |
| 10 | 念的次數是 5 的倍數時（第 5、10、15…次），提示換成「去找真的」：書裡那個東西，家裡的在哪裡？ | |
| 11 | 第 3 次以後才會出現八顆訊號按鈕。六顆好的：她接話了、她指了、她說再一次、她自己去拿的、生活裡說了書裡的詞、她搶先念完。兩顆不好的：有一頁被跳過、念到一半跑掉。可以多選，也可以都不選。 | |
| 12 | 最下面一顆大按鈕「念完了」。按下去記一筆（含剛才選的訊號），訊號全部取消選取，蘿蔔抖一下，新葉子彈出來，卡片顯示一句完成語（22 句輪流），提示的標題從「今晚試試」變成「明晚試試」，按鈕字變成「又念了一次」。 | |
| 13 | 一個晚上可以連按很多次，每按一次就多一筆。沒有上限，也沒有復原。 | |
| 14 | 點一下蘿蔔，它會抖一下。 | |
| 15 | 「她搶先念完」累積 2 次，蘿蔔開始左右搖，卡片寫「可以拔了。」按住往上拖，拖過一半多一點（55%）放手就拔起來；沒過就彈回去。 | |
| 16 | 拔起來之後，主畫面顯示整根蘿蔔，小字多一句「已經拔起來了」。「念完了」還是可以按，次數照樣往上加。 | |

## 書架（從底部滑出）

| # | 實際行為 | 你的反應 |
|---|---|---|
| 17 | 列出所有書，每本顯示封面、書名、念了幾次，現在選的那本有個勾。拔起來的書也在裡面。 | |
| 18 | 點一本就切換過去，書架收起來。 | |
| 19 | 下面可以加一本：打書名，旁邊相機按鈕可以拍照或選照片當封面。照片會裁成正方形小圖。 | |
| 20 | 書不能改名、不能刪、不能補封面。第一本書（用開場畫面加的）也沒有機會放封面。 | |
| 21 | 點書架外面的暗色區域可以關掉。 | |

## 蘿蔔田（左邊那頁）

| # | 實際行為 | 你的反應 |
|---|---|---|
| 22 | 標題下一行：「N 本書，一共念了 N 次」。 | |
| 23 | 「還在土裡」：一排三格，每格一根小蘿蔔、書名、次數。點一格會切到那本書並滑回主畫面。 | |
| 24 | 「拔起來的」：橫向一排拔出來的蘿蔔，照拔的先後排，念越多次的越長。沒有任何一根時寫「她能搶先把整本念完的那天，就可以拔第一根。」 | |
| 25 | 「這週」：往回算 7 天（從現在這一刻往前 7×24 小時），一共念了幾次、每本幾次。 | |
| 26 | 「第一次出現」：這 7 天內，某本書第一次被記到某個好訊號，會列出來，最多 6 條。 | |
| 27 | 某本書的「有一頁被跳過」或「念到一半跑掉」累積 2 次，會出現一張提醒卡，請你先檢查念法和時段。這個 2 次是從頭累積的，不限這週。 | |

## 設定（右邊那頁）

| # | 實際行為 | 你的反應 |
|---|---|---|
| 28 | 「她的名字」可以填。填了會存起來，但 app 裡沒有任何地方用到它，所有文字一律寫「她」。 | |
| 29 | 「睡前提醒」開關是假的，按了沒反應。旁邊註明要等原生版。 | |
| 30 | 「念法，五個字」：等、接、加、誇、再，各一句說明。 | |
| 31 | 匯出備份：下載一個檔名帶日期的 JSON 檔。 | |
| 32 | 匯入備份：選一個 JSON 檔，直接蓋掉現在所有資料，不會再問一次。 | |
| 33 | 載入示範資料：直接蓋掉現在所有資料，換成 6 本假書（最多的念了 47 次），不會再問一次。 | |
| 34 | 清掉全部資料：按一次字變成「再按一次，真的清掉」，再按才清。 | |

## 外觀

淺色、深色跟著手機系統走。主色是綠色。蘿蔔目前是程式畫的簡單圖形，程式裡註明「占位圖形，之後換黏土插圖」。尊重系統的「減少動態效果」設定，開了就不播動畫。
