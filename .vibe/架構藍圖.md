# 架構藍圖（鎖定基準）

> 2026-11-15 定。這張是基準，之後 AI 改任何東西都不能偏離；要偏離先回來改這張，經多米確認。
> 目前還沒有程式，所以方塊後面沒有檔名。有程式之後會補一張「哪個檔案對到哪個方塊」的圖。

## 白話走一遍

打開 app，先到主畫面。主畫面中間是現在這本書的蘿蔔，下面是今晚的提示和「念完了」。

如果這本書有書頁（多米做的客製化書），主畫面多一顆「開始念」。按下去進翻書畫面：一頁一張大圖，字在圖下面，左右滑翻頁，大人的念法提示用小字放在最底下。翻過最後一頁，後面多一頁給大人：念過 3 次以後這裡會有八顆訊號，再一顆「念完了」，按下去回主畫面，葉子長一片。

如果這本書沒有書頁（市售繪本，只有書名），沒有「開始念」。紙本念完，直接在主畫面按「念完了」，跟原型一樣。

主畫面往右滑是蘿蔔田，往左滑是設定，跟原型一樣。

書怎麼進來：多米在電腦上把書做成一個書檔，用 AirDrop 或傳訊息丟給姊姊的手機，點開就問「要把《小芽的鞋子》加進書架嗎」，按好就進來了。

## 流程

```
打開 app
  └─ 主畫面
       ├─ 沒有書 → 打書名 → 種下去
       ├─ 書名膠囊 → 書架
       │     ├─ 點一本 → 切換
       │     ├─ 加一本（書名＋封面）
       │     └─ 改名／補封面／刪除 ⚠️
       ├─ 開始念（有書頁才有）→ 翻書畫面 → 最後一頁 → 念完了
       ├─ 選訊號（第 3 次後）
       ├─ 念完了 → 記一筆 → 長葉子 → 觸覺
       │     └─ 收回剛剛那筆
       └─ 可以拔了 → 往上拖 → 拔起來
  ← 蘿蔔田（還在土裡／拔起來的／這週）
  → 設定
        ├─ 孩子的名字
        ├─ 睡前提醒（開關＋時間）
        ├─ 念法五個字
        └─ 備份：匯出／匯入 ⚠️／清空 ⚠️

從 app 外面點開書檔 → 確認 → 加進書架
```

## 書檔長什麼樣

一個副檔名 `.luodubook` 的檔案（2026-11-15 改：原本寫壓縮檔，實作時改成單一個 JSON 檔，圖直接放在裡面。iPhone 沒有內建解壓縮的功能，用壓縮檔就得另外裝別人的程式庫）。裡面是：

- 書名、代號、每頁的字、每頁給大人的提示
- 每頁一張圖
- 一張封面

圖上不放字，字由 app 排（書稿 2-13 第 5 條）。之後要升級成三歲版，只換說明裡的字，圖不用動。

小芽的書檔不放進 GitHub。這個 repo 是公開的，書稿 2-10 說客製化的書不公開。repo 裡只放一本沒有個人資料的範例書，測試用。

## 哪些方塊互相獨立

- B 規則、C 蘿蔔圖：只吃數字，不碰別人，可以先做、可以同時做。
- F 蘿蔔田、G 設定的名字和五個字：只讀 A，互不相干。
- H 翻書畫面、I 書檔匯入：跟蘿蔔那半邊只在「念完了」那一下接起來。
- J 提醒、K 觸覺：外掛，最後加，拿掉也不影響其他。
- 不獨立的：D 主畫面同時用到 A、B、C、E，要等前面幾塊好了才能做。

## 跟考古版的差別

多了 H、I、J、K、L 五塊，E 多了改名和刪除，D 多了收回，G 少了「載入示範資料」。其餘照原型。

## 資料搬家

原型的匯出備份檔（JSON）原生版要讀得進來。小芽家如果已經用原型記了一陣子，匯出再匯入，紀錄就過來了。
